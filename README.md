📊 Sobre o projeto

Dashboard desenvolvido no Power BI para análise de vendas de um e-commerce ao longo de 2023.

O objetivo é transformar os dados de vendas em informações visuais para acompanhamento de faturamento, pedidos, quantidade de itens, produtos, categorias e canais de venda.

🎯 Principais indicadores

Faturamento: R$ 485,20 mil

Quantidade de pedidos: 175

Quantidade de itens vendidos: 952

📈 Análises disponíveis

O dashboard apresenta:

Evolução do faturamento ao longo dos meses;

Ranking de vendas por produto;

Faturamento por categoria;

Métodos de pagamento;

Representatividade das vendas por canal;

Comparação entre categorias e produtos;

Filtros por período e produto.

🔎 Filtros

O usuário pode utilizar os filtros disponíveis no painel para analisar:

Data da venda

Produto

Esses filtros permitem uma análise mais específica dos resultados.

🛠️ Ferramentas utilizadas

Power BI

Power Query – transformação e preparação dos dados

DAX – criação de medidas e indicadores

Modelagem de dados

Visualizações interativas

💡 Principais perguntas que o dashboard ajuda a responder

Como o faturamento evoluiu ao longo do período?

Quais produtos apresentam maior volume de vendas?

Quais categorias geram mais faturamento?

Qual é o principal método de pagamento?

Qual canal representa a maior participação nas vendas?

Como os resultados mudam ao selecionar determinado produto ou período?

📌 Objetivo profissional

Projeto desenvolvido como prática de Business Intelligence e análise de dados, demonstrando conhecimentos em Power BI, construção de dashboards, indicadores, modelagem e apresentação de informações para apoio à tomada de decisão.
